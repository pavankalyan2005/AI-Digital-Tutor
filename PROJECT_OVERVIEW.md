# AI Digital Tutor - Smart Career & Skill Development Platform

## 🚀 Overview
A comprehensive AI-powered learning platform with 50+ screens, built with React, TypeScript, Tailwind CSS v4, and modern UI components.

## ✨ Key Features Implemented

### 🎯 Core Features
- **AI Personal Tutor Assistant** - Interactive chat with AI mentor
- **Personalized Learning Roadmaps** - Customized learning paths
- **Digital Skills Curriculum** - 500+ courses across 12+ categories
- **Progress Tracking Dashboard** - Advanced analytics and visualizations
- **Coding Practice Arena** - Interactive code challenges with live testing
- **Gamification System** - Streaks, points, achievements, and badges

### 🎨 Design System
- **Futuristic UI** - Modern, clean, startup-level design
- **Glassmorphism Effects** - Translucent cards with backdrop blur
- **Gradient Themes** - Electric blue to purple gradients
- **Neon Accents** - Cyan highlights for AI elements
- **Dark/Light Themes** - Fully responsive theme switching
- **Smooth Animations** - Motion/Framer Motion for fluid transitions

### 🛠 Technology Stack
- **Frontend**: React 18.3.1 + TypeScript
- **Routing**: React Router 7.13.0 (Data Mode)
- **Styling**: Tailwind CSS v4.1.12
- **UI Components**: Radix UI + shadcn/ui
- **Animations**: Motion (Framer Motion) 12.23.24
- **Charts**: Recharts 2.15.2
- **Icons**: Lucide React
- **Theme**: next-themes for dark/light mode
- **Forms**: React Hook Form 7.55.0
- **Build Tool**: Vite 6.3.5
